Usage

This interactive (HTML) or fixed report (PDF) will provide information for a genome-wide association study (GWAS) using the NemaScan (Widmayer et al., 2022) mapping process. The GitHub repo can be found here.

Strain Issues

All strain names are converted to the isotype reference strain name, which can be queried here. If you submitted replicate data for an individual strain, these data were averaged to one mean value for that strain. Isotype reference strains are used because other strains in the isotype are highly similar at the genotype level. Inclusion as separate strains in the GWAS will give incorrect mappings. For some strains, the historical strain name has been replaced with a new isotype reference strain (e.g., CB4858). We found that many of these old CB strains were not the correct genotype and differed between the source lab, the CGC, and other labs in the community. Please see strain issues (C. elegans, C. briggsae , and C. tropicalis) for a more complete explanation.

Manhattan Plots

A genome-wide association study (GWAS) was performed by testing the correlation of a marker genotype difference with a phenotypic variation. These tests correct for relatedness among individuals in your mapped population using a genomic relatedness matrix (or “kinship matrix”) and the first principal component of the genotype matrix comprising the mapped strain genotypes. This analysis was performed with GCTA using two different kinship matrices: one constructed specifically with inbred model organisms in mind (INBRED) and one which is constructed from all markers except those on the chromosome of the tested marker (“leave-one-chromosome-out”; LOCO). The INBRED kinship matrix more heavily corrects for genetic stratification at the tested marker, and the LOCO kinship matrix does not, and could therefore increase power in certain contexts.

  • Every point is a SNV marker used in the GWAS test.
  • Points are colored red if they pass the genome-wide corrected significance threshold:
    • The horizontal solid line corresponds to a stricter Bonferroni (BF) threshold, which is based on the number of markers in the analysis.
    • The horizontal dash line corresponds to a more permissive EIGEN threshold, which corrects for the number of independent markers in your data set. This threshold takes advantage of the extensive LD in selfing Caenorhabditis species to limit the number of “unique” markers. (See Zdraljevic et al. 2019 (PMID: 30958264) for more information)
    • If you selected a custom threshold, only this threshold is shown as a dotted line.
